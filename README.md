# 17-0: AMA Supercross Draft

Draft legendary AMA Supercross champions across the eras and try to win every race in a 17-round stadium SX season. 84 legends. 6 eras. 17 rounds. 1 goal: 17-0.

## Quick Start
Open `index.html` in any browser. No build, no dependencies.

## Game Loop
1. Pick 5 SX legends from 6 eras (Pre-2000 to 2022-2026)
2. Era Synergy: extra drivers from same era get +1.5 OVR
3. Race through 17 stadium rounds (Anaheim 1 to Las Vegas Finale)
4. Try to win every round = 17-0 perfect season

## Matrix Position
X-0 Sports Draft template #21 (forked from WSBK 24-0).

## Difficulty
- OVR 70-85: backmarker (0 wins avg)
- OVR 90: mid-pack podiums
- OVR 95: title contender (~6 wins avg)
- OVR 99: GOAT tier (~13 wins, 3% perfect)
